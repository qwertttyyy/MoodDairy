# MoodDiary

Дневник настроения для наблюдения за эмоциональным состоянием:
записи, графики и возможность поделиться данными с врачом.

[Открыть приложение](https://moods.qwertttyyy.ru/)

## Возможности

- Записи настроения по шкале 1–9, уровень тревоги, заметки и теги.
- Графики изменения настроения с фильтрами по периодам.
- Шифрование чувствительных данных в браузере до отправки на сервер.
- Передача выбранных записей врачу по специальной ссылке.
- Светлая и тёмная темы, адаптация для мобильных устройств.
- Установка как PWA.
- Чтение загруженных записей без интернета и создание новых
  с последующей синхронизацией.

## Стек

- **Frontend:** React 19, TypeScript, Vite, TanStack Query, Zod, Workbox.
- **Backend:** Python 3.12, Django 6, Django REST Framework.
- **Хранение и кеш:** PostgreSQL 16, Redis 7.
- **Инфраструктура:** Docker Compose, nginx, GitHub Actions.

## Локальный запуск

Потребуются Docker с Compose и Node.js 22 с npm.

1. Склонируйте проект и подготовьте окружение:

   ```bash
   git clone https://github.com/qwertttyyy/MoodDairy.git
   cd MoodDairy
   cp .env.example .env
   ```

   В `.env.example` уже указаны настройки для локального запуска.

2. Запустите бэкенд, PostgreSQL и Redis:

   ```bash
   docker compose up -d --build
   ```

   Миграции применяются автоматически.

3. Запустите фронтенд:

   ```bash
   cd frontend
   npm ci
   npm run dev
   ```

Откройте http://localhost:5173 и зарегистрируйте аккаунт.
Бэкенд доступен на http://localhost:8000; фронтенд проксирует запросы к API.
